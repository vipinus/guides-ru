# 05 · «Приватная» сеть (Tailscale): установка, вход на управляющий сервер сайта, выбор выхода

> Версия на сайте (подробнее): https://www.leotun.com/ru/guides/tailscale-mesh?utm_source=github&utm_content=client-05

Раздел «Приватная» использует Tailscale (инструмент для объединения устройств в сеть на основе WireGuard). У LeoTun свой управляющий сервер, и входите вы **с аккаунтом на этом сайте** — к официальному аккаунту Tailscale он отношения не имеет. Войдите один раз — и устройство остаётся онлайн; регион выхода можно в любой момент сменить в меню. Чем это отличается от VPN и кому подходит, см. [Руководства по сети 03](../network/03-private-network-vs-vpn.md).

## Установка

| Платформа | Где взять |
|---|---|
| Windows / macOS / Linux / Android | Раздел загрузок на [странице «Приватная» на сайте](https://www.leotun.com/ru/mesh?utm_source=github&utm_content=client-05) (раздаётся прямо с этого сайта, на официальный сайт идти не нужно) |
| iPhone / iPad | App Store; нужен Apple ID не китайского региона (см. [Клиенты 06](06-ios-app-store.md)) |

## Вход

1. **Сначала выйдите из официального аккаунта** (если когда-нибудь в него входили): на телефоне нажмите на аватар → Log Out; на компьютере выполните `tailscale logout`. Пока вы полностью не вышли, нужный на следующем шаге пункт не появится.
2. **Направьте вход на этот сайт**:
   - Телефон: на экране после выхода нажмите «⋯» в правом верхнем углу → Use custom server (в некоторых версиях — Use an alternate server), введите адрес со страницы «Приватная» на сайте и нажмите Log in.
   - Windows / Linux: скопируйте со страницы сайта команду `tailscale up --login-server=…` и выполните её в PowerShell / терминале.
   - macOS: **не нажимайте Log in**. В окне Tailscale нажмите стрелку в строке аккаунта → Account Settings… → Accounts → маленькая стрелка рядом с «Add Account…» → Add Account Using Alternate Server, вставьте адрес и нажмите Add Account….
3. Браузер сам откроет страницу входа этого сайта; подтвердите вход своим аккаунтом на этом сайте. Вернувшись в клиент, вы увидите, что он уже онлайн.

## Выбор выхода

- Телефон: меню → Exit Node, выберите регион; действует сразу.
- Компьютер: значок в трее / строке меню → подменю Exit Node; или `tailscale set --exit-node=<region-name>` (`tailscale exit-node list` покажет, что доступно).
- Чтобы не использовать выход, выберите None (в командной строке оставьте пустым значение после знака равенства). Одновременно можно использовать только один выход.

## Срок действия и число устройств

- Вход на устройстве действует до окончания срока аккаунта; после окончания устройство уходит в офлайн в течение нескольких минут; после продления просто войдите ещё раз. Переустанавливать ничего не нужно.
- Число устройств онлайн одновременно зависит от тарифа («Личный» — 2, «Семейный» — 4, «Корпоративный» — 8), и этот лимит общий с другими способами подключения; если вы превышаете лимит тарифа, можно временно перейти на тариф выше (оставшееся время пересчитывается по цене в равной стоимости) и потом вернуться.

## Два случая, когда лучше другой способ

- На том же устройстве работает другой VPN (корпоративный AnyConnect, другая программа для объединения устройств в сеть): они дерутся за DNS и маршруты. Отсюда и сообщения об авторских правах при просмотре китайского видео, и не открывающаяся внутренняя сеть компании.
- В сети кампуса или компании, где ограничен UDP: WireGuard работает по UDP, поэтому трафику остаётся идти только через ретрансляторы Tailscale, а это очень медленно; переходите на AnyConnect.

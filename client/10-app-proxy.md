# 10 · Что делать, если Dropbox и другие программы просят HTTP- или SOCKS-прокси

> Версия на сайте (подробнее): https://www.leotun.com/ru/guides/app-proxy?utm_source=github&utm_content=client-10

**Сначала о главном: прокси обязательно должен быть зашифрован.** Незашифрованные прокси (обычный HTTP, SOCKS4, SOCKS5) в сетях Китая распознают и глушат: через некоторое время соединение замедляется или рвётся, а аккаунт и пароль к тому же передаются открытым текстом. Долго работают только зашифрованные соединения, поэтому «Веб Прокси» этого сайта везде использует шифрование; **для программ, которые принимают только HTTP / SOCKS5, пусть весь компьютер берёт на себя Hiddify** (см. ниже).

Отдельные программы — Dropbox, Telegram Desktop, Steam, клиенты облачных дисков, инструменты разработчика — не читают настройки браузера, а в их собственных настройках прокси можно указать только незашифрованный HTTP / SOCKS5. Одно с другим не совпадает, поэтому, сколько ни вводи прокси, подключения нет. Решение — **не вводить прокси вообще**: пустите весь компьютер через линию с помощью Hiddify, а в программе выставьте «Без прокси».

## Почему после ввода прокси всё равно не подключается

| Причина | Пояснение |
|---|---|
| Несовпадение типов | Программа предлагает только HTTP, SOCKS4 и SOCKS5, и ни один не зашифрован; прокси этого сайта обязательно зашифрован, и его туда не ввести |
| Незашифрованный прокси из интернета | Какое-то время работает, потом его начинают глушить, и он работает с перебоями |
| Покрывает только часть трафика | Во многих программах через прокси идут только вход и синхронизация, а обновления, звонки и синхронизация по локальной сети по-прежнему идут напрямую; UDP-трафик игр и звонков HTTP-прокси вообще не пропускает |
| Настраивается в каждой программе отдельно | При смене региона или пароля менять придётся везде по очереди, и где забудете — там перестанет работать |

## Рекомендуемый способ: пусть Hiddify возьмёт на себя весь компьютер

1. Установите Hiddify по статье [09 · Установка Hiddify на всех платформах](09-hiddify-install-all-platforms.md) и импортируйте профиль по статье [02](02-singbox-subscription-links.md).
2. Подключитесь в режиме «VPN» (по умолчанию). В Windows для первого подключения нужны права администратора.
3. Верните в программе настройку прокси на «Без прокси»: в Dropbox в «Настройки → Сеть → Прокси» выберите «Без прокси» или «Автоопределение»; в Telegram Desktop в «Настройки → Продвинутые настройки → Тип соединения» выберите «Не использовать прокси». В любой другой программе с настройкой прокси отключите её.
4. Проверьте: значок Dropbox в трее показывает, что всё синхронизировано (Up to date), и синхронизация пошла; откройте в браузере сайт, показывающий ваш IP, — выход должен быть в выбранном регионе.

С включённой «автоматической маршрутизацией» зарубежные сервисы вроде Dropbox идут через линию, а WeChat, интернет-банк и китайские сайты, как обычно, — напрямую.

## Популярные программы

| Программа | Как настроить |
|---|---|
| Dropbox | Прокси «Без прокси» или «Автоопределение»; если оставить «Вручную» с каким-то другим адресом, при выключенном Hiddify он останется офлайн |
| Telegram Desktop | Тип соединения «Не использовать прокси»; встроенный MTProto / SOCKS5 поверх туннеля только замедляет |
| OneDrive, Google Drive, iCloud для компьютера | Следуют системной сети; настраивать нечего |
| Steam, Epic, Battle.net | Прокси не нужен; если загрузки медленные, выберите регион поближе |
| Zoom, Teams, Slack, Discord | Голос и видео идут по UDP, а его переносит только способ для всего компьютера |
| VS Code, JetBrains, Cursor | Следуют системной сети; удалите прокси, если он задан отдельно в самом инструменте |

## Если клиент поставить нельзя (рабочий компьютер)

- Пользуйтесь веб-версией Dropbox и облачных дисков: откройте dropbox.com в браузере с [«Веб Прокси»](03-web-proxy-extension.md); загружать и скачивать можно, но автоматической синхронизации не будет.
- Инструменты командной строки (git, pip, npm, curl) принимают зашифрованный прокси: укажите адрес «Веб Прокси» в `https_proxy`; см. [Доступ к зарубежным сервисам из Китая 05 · Linux и командная строка](https://github.com/vipinus/guides-zh-CN/blob/main/overseas-access/05-linux-server.md) (на китайском).
- Другими настольными программами, которые принимают только HTTP / SOCKS5, лучше пользоваться на своём компьютере или телефоне; не ставьте ради этого VPN на весь рабочий компьютер — это вызовет срабатывание систем безопасности компании.

## Частые вопросы

**Можете дать адрес SOCKS5- или HTTP-прокси?** Прокси этого сайта везде использует шифрование; незашифрованный уже скоро начнёт работать с перебоями. Hiddify на весь компьютер работает стабильнее и сразу покрывает все программы.

**Если Hiddify включён, нужно ли ещё вводить прокси в программе?** Нет. Тогда трафик пойдёт по кругу дважды: в лучшем случае медленнее, в худшем — не подключится.

**А Dropbox на телефоне?** У приложений на телефоне нет настроек прокси. Поставьте Hiddify или Cisco (AnyConnect); после подключения все приложения идут через линию.

**Можно обойтись без Hiddify?** Да. Cisco, «Приватная» сеть и OpenVPN тоже берут на себя весь компьютер, и в программе так же выставляется «Без прокси». Преимущество Hiddify — встроенная маршрутизация и лучшая скорость в сетях с большими потерями пакетов.

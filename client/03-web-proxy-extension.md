# 03 · «Веб Прокси»: настройка расширения ZeroOmega в два шага

> Версия на сайте (подробнее): https://www.leotun.com/ru/guides/web-proxy?utm_source=github&utm_content=client-03

«Веб Прокси» пускает через линию только **этот браузер**, остальные программы в системе не трогает. Клиент ставить не нужно, права администратора не нужны, состояния «подключено» нет — а значит, обрываться в принципе нечему. Подходит для рабочего компьютера, для машины, уже подключённой к корпоративному VPN, или когда через линию нужно пустить только один браузер. Когда им пользоваться, а когда без VPN не обойтись, см. [Руководства по сети 02](../network/02-choose-your-connection-method.md).

## Два шага

1. **Установите расширение**: поставьте ZeroOmega (продолжение SwitchyOmega) в Chrome / Edge / Firefox. Ссылки на установку для каждого браузера — на [странице «Веб Прокси» на сайте](https://www.leotun.com/ru/httpproxy?utm_source=github&utm_content=client-03).
2. **Импорт**: войдите на сайт и на странице «Веб Прокси» нажмите на флаг нужного региона (или «Импортировать все регионы», чтобы добавить сразу все) — скопируется ссылка с настройками. Откройте в расширении «Импорт/Экспорт» (Import/Export), вставьте её в поле «Восстановить из сети» (Restore from online) и нажмите «Восстановить» (Restore). Регионы, адреса и способ шифрования импортируются за один раз, вручную ничего вводить не нужно.

После этого нажмите на значок расширения и выберите регион, затем введите логин и пароль от сайта в окне входа, которое покажет браузер. Чтобы сменить регион, выберите другой в меню значка; чтобы вернуться к прямому подключению, переключитесь на «Напрямую» (Direct).

## В этих случаях нужен способ для всего устройства

- Видео- и музыкальные приложения и плееры: большинство из них не используют прокси браузера, отсюда «страницы открываются, а видео не играет».
- Приложения на телефоне, игры и программы для компьютера. В настройках прокси в программах вроде Dropbox можно указать только незашифрованный HTTP / SOCKS5, а на практике прокси обязан быть зашифрованным, так что «Веб Прокси» этого сайта туда не вписать. Вместо этого возьмите Hiddify, который берёт на себя всё устройство; см. [10](10-app-proxy.md).
- Просмотр Tencent Video или iQIYI из-за рубежа: видеосайты проверяют ещё и IPv6 и DNS, а «Веб Прокси» их не охватывает; нужен VPN на всё устройство.

## Частые вопросы

| Симптом | Причина |
|---|---|
| Окно входа появляется снова и снова | Закончился срок аккаунта или неверный пароль |
| Одни сайты не открываются, другие в порядке | Правила «автопереключения» (auto switch) в расширении пустили их напрямую; попробуйте один раз режим глобального прокси |
| В Китае открываются только HTTPS-сайты | Обычный HTTP по дороге подменяется, проходят только зашифрованные соединения; сейчас почти все сайты на HTTPS |
| Медленно | Смените регион; прокси и VPN используют одни и те же серверы |

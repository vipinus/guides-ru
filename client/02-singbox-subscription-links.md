# 02 · Как импортировать ссылку подписки (Hiddify, Clash, Shadowrocket)

> Версия на сайте (подробнее): https://www.leotun.com/ru/guides/singbox-subscription?utm_source=github&utm_content=client-02

«Ссылка подписки», которую выдают провайдеры прокси-линий, — это просто HTTPS-адрес, с которого клиент скачивает готовую конфигурацию: сервер, порт и данные для входа уже внутри, вручную ничего вводить не нужно. Страница Hiddify в LeoTun даёт то же самое, причём сразу в трёх форматах, так что Hiddify, Clash и Shadowrocket берут каждый свой и ничего не нужно конвертировать.

## Три кнопки во всплывающем окне

Войдите на сайт → страница Hiddify → нажмите на флаг региона. Появится QR-код, а под ним три кнопки. Кнопки разделены **по типу подписки**, а не по операционной системе, поэтому на телефоне и на компьютере набор одинаковый:

| Клиенты, указанные на кнопке | Подпись | Что копируется при нажатии |
|---|---|---|
| Hiddify / sing-box / GUI.for.SingBox / Karing | «Подписка sing-box» | На телефоне — ссылка импорта `sing-box://import-remote-profile?url=…`, которая сама открывает приложение; на компьютере — обычный адрес конфигурации `https://…` для вставки. В конфигурации уже есть правила маршрутизации и правило, отбрасывающее IPv6, так что оборачивать её в «шаблон подписки» не нужно |
| Clash Meta / Clash Verge / FlClash / Stash / Mihomo Party / Clash Nyanpasu / ClashX Meta / OpenClash | «Подписка Clash» | Адрес подписки в формате Clash (YAML), который вставляется в список подписок / профилей клиента |
| NekoBox / Shadowrocket / v2rayN / v2rayNG / Streisand / V2Box / Loon / Egern / Husi / NekoRay / Pharos Pro / Bedlam / Furious / daed / Lumen KVN / Kitty Pro | «Ссылка для обмена» | Одна строка `hysteria2://…`: только узел, без правил маршрутизации |

- Если названия не помещаются в одну строку, они прокручиваются по кругу — так и задумано.
- **Нажатие на кнопку заодно переключает QR-код сверху на этот тип**, чтобы его мог отсканировать подходящий клиент. Когда окно только открылось, QR-код — для Hiddify / sing-box, и другие клиенты, отсканировав его сразу, выдают «Неверный QR-код» (Invalid QR code): сначала нажмите кнопку своего клиента, потом сканируйте или вставляйте.
- В окне «Импортировать все регионы · автовыбор» вверху страницы только первые две кнопки, ссылки для обмена там нет.

**Конвертация подписки** — это сторонние сайты, которые переделывают один формат в другой. LeoTun сразу даёт все три формата, так что **конвертировать ничего не нужно**; отдать ссылку с вашими данными для входа сайту-конвертеру — всё равно что отдать постороннему свой аккаунт, так что не делайте этого.

## Семейство Hiddify / sing-box: первая кнопка

1. Установите Hiddify (Android — со страницы загрузок сайта или из Google Play; iOS — из App Store; настольное приложение — для Windows / macOS / Linux). Ядро sing-box уже встроено.
2. Нажмите на флаг региона — появится QR-код.
3. Телефон: нажмите первую кнопку и перейдите в Hiddify — он предложит добавить профиль из буфера обмена; либо отсканируйте код через «Сканировать QR-код» в Hiddify на другом устройстве. Компьютер: нажмите ту же кнопку — скопируется адрес https://, затем в Hiddify «+» → «Добавить из буфера обмена» и сохраните.
4. Нажмите «Подключить» и при первом запуске разрешите создание VPN. Чтобы добавить ещё регион, нажмите на другой флаг: каждый регион — отдельный профиль.

## Семейство Clash: вторая кнопка

Для Clash Meta (mihomo), Clash Verge, FlClash, Stash и подобных нажмите кнопку «Подписка Clash» и вставьте скопированный адрес в список подписок / профилей клиента. Конвертер подписок не нужен.

**Клиентам семейства Clash ссылка для обмена не подходит**: одну строку `hysteria2://` они как профиль импортировать не умеют.

## Остальные клиенты: третья кнопка

Нажмите кнопку «Ссылка для обмена», затем в NekoBox / Shadowrocket / v2rayN / v2rayNG и т. п. выберите «Импорт из буфера обмена» или после нажатия кнопки отсканируйте QR-код сверху. В ссылке для обмена нет правил, поэтому маршрутизацию и IPv6 придётся настроить самим: если вы за рубежом и хотите смотреть китайский контент, пустите китайские домены через узел и отключите IPv6.

Все клиенты, указанные на кнопке после v2rayN, поддерживают hysteria2, но в ссылке для обмена используется расширенный формат hysteria2, который некоторые клиенты не разбирают; если импорт не удаётся или не подключается, переходите на Hiddify.

## Клиенты, которые не подходят

| Клиент | Почему |
|---|---|
| Surge | Поддерживает hysteria2, но читает только собственный формат конфигурации, так что ни один из трёх типов не подходит |
| Quantumult X | Не поддерживает такой тип линий |
| Оригинальный Clash, Clash for Windows | В ядре нет hysteria2; используйте клиент на ядре mihomo |

## Истекает ли подписка?

- **Со временем не истекает.** Токен в адресе подписки привязан к вашему аккаунту и работает, пока аккаунт действует; после продления или смены тарифа импортировать заново не нужно.
- **Смена пароля сразу делает старый адрес недействительным.** Так отзывают доступ, если потерян телефон или утекла ссылка; после смены пароля отсканируйте код заново.
- **После окончания срока аккаунта** адрес отвечает ошибкой 401; после продления существующий профиль менять не нужно.
- **В профилях, импортированных до сентября 2026 года,** нет правила, отбрасывающего IPv6; удалите их и импортируйте заново.

Если импортировали, но не подключается, см. [Решение проблем 04](../troubleshooting/04-singbox-import-not-connecting.md).

## Частые вопросы

**Чем подписка Hiddify отличается от подписки Clash?** Форматом (JSON и YAML), и клиенты не понимают чужие подписки, но сами узлы работают и там, и там. LeoTun сразу даёт обе: клиенты семейства Clash нажимают кнопку «Подписка Clash», ссылкой для обмена им пользоваться нельзя.

**Можно ли собрать все регионы в одном профиле?** Импорт по флагу даёт отдельный профиль на каждый регион, а переключаетесь вы между ними в списке профилей клиента; так смена адреса одного региона затрагивает только его. Чтобы разом импортировать все регионы за пределами Китая и дать клиенту выбирать автоматически, нажмите вверху страницы «Импортировать все регионы · автовыбор» (там только кнопки «Подписка sing-box» и «Подписка Clash»).

**Можно ли отправить QR-код родственникам?** В QR-коде ваши данные для входа: кому отправили — тот получил ваш аккаунт. Делиться с семьёй можно (одновременно онлайн по тарифу: «Личный» — 2 устройства, «Семейный» — 4, «Корпоративный» — 8), но не публикуйте код в открытом доступе; если он утёк, смените пароль — и он перестанет работать.

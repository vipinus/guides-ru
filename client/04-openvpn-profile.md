# 04 · OpenVPN: скачать профиль .ovpn, импортировать и подключиться; работает на роутерах, NAS и Linux

> Версия на сайте (подробнее): https://www.leotun.com/ru/guides/openvpn-setup?utm_source=github&utm_content=client-04

OpenVPN — давно существующий открытый протокол, клиент для него есть почти в каждой операционной системе, прошивке роутера и NAS. Профили LeoTun уже содержат ваш аккаунт, пароль и ключи шифрования, так что подключиться можно сразу после импорта. Для повседневного использования на телефонах и компьютерах проще AnyConnect или Hiddify; OpenVPN ценен там, **где принимают только OpenVPN**: роутеры с OpenWrt, NAS Synology / QNAP, Linux-серверы и старые устройства.

## Три шага

1. По таблице на [странице OpenVPN на сайте](https://www.leotun.com/ru/openvpn?utm_source=github&utm_content=client-04) установите клиент для своей системы (на всех платформах есть официальный OpenVPN Connect; в Windows можно также использовать OpenVPN GUI, в macOS — Tunnelblick).
2. Войдите на сайт и **нажмите на флаг региона**, чтобы скачать .ovpn этого региона. Один файл — один регион.
3. Откройте файл в клиенте и подключитесь.

| Платформа | Примечание |
|---|---|
| Windows / macOS / Android / iOS | В профиль уже встроены аккаунт и пароль; импортируйте и подключайтесь |
| Linux | Системные настройки VPN → импорт из файла, при первом подключении введите email и пароль от сайта; из командной строки `openvpn --config file`; для запуска при загрузке положите файл в `/etc/openvpn/client/` |
| Роутер с OpenWrt | Установите luci-app-openvpn, загрузите .ovpn и включите; если стоит прошивка этого сайта, не нужно |
| NAS Synology | Панель управления → Сеть → Сетевой интерфейс → Создать → VPN → OpenVPN (импорт .ovpn); чтобы исходящий трафик NAS шёл через линию, отметьте «Use default gateway on remote network» (использовать шлюз по умолчанию в удалённой сети) |
| NAS QNAP | QVPN → VPN Client → Add → OpenVPN, импорт |

## Для тех, кто в Китае: китайские сайты напрямую

После подключения трафик к китайским сайтам идёт в обход. На сайте есть «инструмент прямой маршрутизации для Китая»: запустите его двойным щелчком, и китайские IP будут подключаться напрямую, а всё остальное — через линию. Работает и с Cisco, и с OpenVPN. Тем, кто за рубежом, он не нужен.

## Если не подключается, проверяйте по порядку

| Ключевое слово в логе / симптом | Причина | Что делать |
|---|---|---|
| AUTH_FAILED | Неверный аккаунт или пароль либо срок истёк | Войдите на сайт и проверьте дату окончания; если меняли пароль, скачайте профиль заново |
| Сначала таймаут по UDP, потом подключается по TCP | Текущая сеть ограничивает UDP, и клиент автоматически перешёл на TCP | Пользоваться можно, но медленнее; если слишком медленно, смените сеть или используйте AnyConnect |
| И по UDP, и по TCP ошибка TLS handshake failed / key negotiation failed | Сетевой путь до сервера не работает | Смените регион или сеть |
| Ошибка при импорте | Слишком старый клиент (до OpenVPN 2.5) | Обновите клиент |
| Внезапный обрыв во время работы | Срок аккаунта истёк, и сервер вас отключил | Продлите и переподключитесь; профиль менять не нужно |

## UDP или TCP

Доступны оба, выбирать не нужно. В профиле UDP стоит первым, поэтому клиент сначала пробует UDP; если UDP ограничен или не подключается, через несколько секунд он сам переходит на TCP. У UDP ниже задержка и выше скорость; TCP — только запасной вариант и через границу заметно медленнее. В сетях, где UDP ограничен постоянно (некоторые сети университетов и компаний), советуем сразу пользоваться AnyConnect.

> Профили, скачанные до 15 сентября 2026 года, содержат только UDP; скачайте заново, если нужно автоматическое переключение.

## Безопасность

В файле профиля есть ваш аккаунт и пароль, то есть он равноценен самому аккаунту — не передавайте его другим; если он утёк, смените пароль на сайте, и старый файл сразу перестанет работать. Само рукопожатие тоже зашифровано: без ключа из профиля его даже не начать, и сканеры сервер не видят.

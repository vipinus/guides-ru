# 02 · Как смотреть китайское видео из-за рубежа

> Версия на сайте (подробнее): https://www.leotun.com/ru/guides/overseas-video?utm_source=github&utm_content=china-access-02

## Почему не показывает

Платформы покупают права только на материковый Китай и блокируют все зарубежные IP подряд. Это не технический сбой, и единственное решение — сменить IP.

## Чем отличаются платформы

| Платформа | Сайт | Приложение | Примечания |
|---|---|---|---|
| iQIYI | Достаточно сменить IP | Достаточно сменить IP | Международная версия iQIYI — другое приложение, контента там меньше; не поставьте не то |
| Tencent Video | Достаточно сменить IP | Достаточно сменить IP | То же с международной версией WeTV |
| Youku | Достаточно сменить IP | Достаточно сменить IP | |
| Mango TV | Достаточно сменить IP | Достаточно сменить IP | |
| Bilibili | Большую часть можно смотреть и так | Так же | Ограничения по региону только у части аниме и документальных фильмов |
| Yangshipin / CCTV | Достаточно сменить IP | Так же | Прямые эфиры каналов сильнее всего чувствительны к IP |

**Ловушка с международной версией приложения**: если в зарубежном магазине искать iQIYI по китайскому названию, обычно находится международная версия iQIYI с совершенно другим каталогом. Чтобы смотреть китайский каталог, нужна версия приложения для материкового Китая; на iPhone для этого нужен Apple ID китайского региона, на Android можно поставить APK напрямую.

## Подключено, а всё равно пишет про авторские права

Если выходной IP уже из материкового Китая, а сайт всё равно пишет про ограничения по авторским правам, в девяти случаях из десяти **IPv6 или местный DNS устройства идут в обход линии**. С сентября 2026 года во всех трёх способах LeoTun, подключающих устройство целиком, IPv6 блокируется на стороне линии; конфигурации Hiddify, импортированные до сентября, нужно удалить и заново импортировать по QR-коду. Порядок проверки — в статье [Подключено, а видеосайт всё равно пишет про авторские права: утечки через IPv6 и DNS](../troubleshooting/03-ipv6-and-dns-leak.md).

## Смотреть на телевизоре

На телевизор и ТВ-приставку клиент не поставить, поэтому есть два пути:

1. **Через роутер**: настройте линию в Китай на роутере и включите раздельную маршрутизацию — телевизору достаточно подключиться к этому Wi-Fi. Выигрывает вся семья; см. [Для пожилых родственников и телевизора](../router/04-family-tv-and-router.md).
2. **Трансляция экрана**: включите линию в Китай на телефоне и транслируйте на телевизор. Просто, но телефон должен всё время оставаться включённым.

## Качество картинки

Для 1080p нужно стабильно 5 Мбит/с и больше. Если в вечерний час пик видео подтормаживает, выберите регион с зелёным индикатором или смените способ подключения; если всё равно тормозит, обычно виноват местный интернет. Точка входа поближе к вам и с оптимизированным каналом до материкового Китая поможет больше, чем смена платформы.

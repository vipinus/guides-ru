# Доступ к Китаю из-за рубежа · Всё, для чего нужен китайский IP

За границей многие китайские сервисы вас не пускают, потому что ваш IP не из материкового Китая: видео, музыка, госуслуги, банки, покупка билетов, игры. На каждую ситуацию — отдельная статья, где понятно объяснено, **почему вас блокируют, как это исправить и какие ещё есть подводные камни**.

**Самая востребованная статья: [Как открыть китайские видеосайты из-за рубежа с помощью роутера](../router/06-unlock-chinese-video-with-router.md)** — телевизор, ТВ-приставка и все домашние устройства настраиваются один раз, и iQIYI, Tencent Video и Yangshipin работают сразу после подключения к Wi-Fi.
